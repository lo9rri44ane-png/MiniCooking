## 运行表现

左侧改为艺术字步数计数器，关卡移到右侧。订单暂时只显示图标：成品居于右上凹槽中心，原材料使用固定最多3槽、统一图标框，保留设备提示和配送勾选。

满包时先完整播放1.1秒仓鼠满包动作，再在背包UI连续播放两次0.55秒微红柔光，最后出现失败界面。退出/重试取消旧演出；客人演出仍不锁操作。

## 验证

64项自动测试与类型检查通过。`previews/actors-hud-browser.json` 记录第1/10/12关真实预览、艺术字计数、纯图标订单、统一材料槽、角色脚锚/大小及满包流程；第11关通过真实滑动路线 `down,left,up,right,down,right` 触发满包，实测完整动作至失败弹窗约2.24秒，期间记录两次柔光峰值。结果后重试与退出未出现迟到弹窗；演出中直接打断的取消路径经代码检查。

原教程5组、客人非阻塞6组回归通过；素材审计覆盖100角色帧和11项UI，运行副本与分类备份哈希一致。未打包、提交或推送远端。

## UI生成提示词

内置imagegen，透明背景、完整轮廓：暖珊瑚红/橙色内衬、金色奶油倒角的宽圆角步数面板，左半准确显示“步数：”，右半留空；风格为温暖Q版厨房游戏的柔软立体UI。数字单独5列2行排列0–4、5–9，奶油白正面、金色倒角和深暖红阴影，统一高度与基线，完整透明安全边距；禁止合并、倾斜、缺字和变形。
