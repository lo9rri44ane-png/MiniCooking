# 早餐店序列帧与场景交付

已接入 Creator 3.8.8 游戏预览。主角是仓鼠，客人为狗、兔、熊；客人、气泡与烟雾独立于背景。整块透视棋盘保存在场景的“厨房棋盘底图”，逻辑格子和滑动命中共用透视投影。

## 资源与模板

|内容|数量/状态|
|---|---|
|仓鼠|13组：空包、1–3格、4–7格待机，吃不下，四向移动、四向制作，下班庆祝|
|狗/兔/熊|每位4组：出现、待机、满足庆祝、消失|
|共用烟雾|出现、消失2组|
|阳光|1组4帧，默认0.5 FPS|
|全部动画|28组112帧；另有5张场景/棋盘/气泡图|

`source/` 保留生成原图，`exports/` 严格分类保存运行资源备份，`manifests/` 保存源图与导出尺寸、SHA256、帧序列、裁切与逐张审计。运行副本位于 `assets/resources/art/breakfast-v3/`，与备份逐文件一致。联系图在 `previews/audit-*.png`，完整性审计为 `manifests/animation-audit.json`。

原生模板位于 `assets/resources/prefabs/`：ChefBody、CustomerActor、IngredientTile、DeviceTile、OrderBubble、CartoonSmoke、SunlightOverlay。角色模板带可编辑默认帧；全项目当前49个原生prefab。场景和模板由编辑器序列化，不手写scene/prefab/meta。

## 调整方式

`assets/scripts/features/kitchen/KitchenPresentationConfig.ts` 集中调整移动秒/格（0.18）、制作秒（3）、客人出现/消失、气泡、勾选、庆祝、烟雾时间以及阳光FPS。制作时仅设备美术子节点播放果冻，完成或取消后复原。

通用中文组件 `assets/scripts/framework/cocos/序列帧播放器.ts` 支持帧数组、FPS、循环、总时长覆盖、完成回调、暂停/恢复和停止取消。动画使用固定画布和脚底锚点，角色和按钮保持等比缩放。

客人演出不锁操作。出现与气泡完成后才参与订单；若此时厨师停在制作台，会原地重新检查，不多扣步。满足后先勾选旧菜品，再收气泡、庆祝、伴随烟雾离场，槽位可用后接下一客人。暂停冻结演出；撤回、重试、退出取消旧回调。

## 已验证与边界

60项自动测试及类型检查通过。真实预览报告 `previews/customer-readiness-browser.json` 覆盖未出现不扣料、就绪原地制作、退场中继续移动、暂停恢复、撤回、重试、切关与首页场景节点归属；`previews/animation-browser.json` 记录拾取后HUD节点保持与制作/胜利流程。

117张导出均已逐张轮廓复查、备份哈希核对，审计无阻断项。整张厨房和阳光是允许铺满的背景/光场，其余主体保留透明边距。旧版被拒绝切图仅留审计备份，不回流运行目录。

95%效果图还原仍是视觉验收目标，尚未作此达标声明。当前实现为2D序列帧，未引入骨骼动画，也未打包或推送远端。
