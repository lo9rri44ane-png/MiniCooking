# 棋盘嵌入背景与仓鼠居中

本轮恢复棋盘重做。以现有v4厨房背景的原地面内缘为唯一外框，分别将4×4、5×5、6×6瓷砖网格画进原背景空地，再提取地面。未采用此前独立棋盘草稿，也未给地面添加第二个框。

## 资源与几何标准

- `source/boards/`：内置imagegen编辑的完整背景原图，分别16/25/36格；改动目标仅原地面网格，背景位置和透视作为参照。
- `exports/board/`：620×600棋盘PNG备份；运行副本为 `assets/resources/art/breakfast-v6/board/`。
- 全部整图保持原始比例，统一缩至720画幅，再取相同位置crop `(50,377,620,600)`，使用同一个原内缘圆角梯形alpha轮廓。地面自然表面在原边框下裁切，角色轮廓不参与此操作。
- 原v4背景继续使用，棋盘场景中心固定 `(0,-37)`。不同规格的可见总外缘一致，格子少则格子大。
- 每张图按实际横缝、各列顶底交点单独记录标定，格中心与滑动命中使用同一套数据；可见边界以统一mask为准，不将生成原图延伸到mask外的部分算入格子。
- `manifests/boards.json`、`board-audit.json` 保存源图/输出SHA、边界、标定与逐张目视审核；`previews/` 保存合成、中心点对照与真实运行截图。

## 仓鼠中心

仓鼠改为画布中心锚 `.5`，可见主体中心对齐逻辑格中心；保留v5动作尺寸和客人身体校准。旧脚底锚会令整个主体悬在格心上方。52张仓鼠帧的可见中心检查由 `ChefVisualAlignment.ts` 与相应测试覆盖，运行中再将Sprite实际中心转换到棋盘坐标验证。
