# 小游戏框架方案
用户直接授权实施。采用轻量TS核心+Cocos适配层，不引入重型业务框架。默认720×1280竖屏可修改，不代表玩法决定。
核心：事件、版本化存档、异步路由、资源引用、对象池、平台接口。适配：音频、资源、页面、安全区、前后台。应用：启动和框架检查页面；业务放features。
保留官方main.scene及meta，运行时创建UI。不选择具体玩法，不伪装平台SDK，不另开引擎或打包。新增脚本资源需要编辑器生成meta，未打开引擎则说明待导入和预览。
# 2D 优化补充
- 启动场景固定Canvas/UICamera，Application由编辑器挂载Canvas，不再由全局事件创建第二套启动节点。
- 只保留2D/UI必要模块；物理、Spine、地图等具体游戏用到再开启。
- 不再保留官方3D示例；旧资源备份放在工程外，避免被引擎导入。
