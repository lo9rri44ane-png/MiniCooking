# 餐厅关卡链条与新手引导

日期：2026-10-30。引擎：Creator3.8.8。当前为无正式美术的可玩版本。

## 玩家流程
首页 → 选择餐厅 → 店内关卡（每10关一页）→ 新内容引导 → 关卡 → 胜败结算 → 下一关。
同店关卡顺序解锁，通关前一关后开放后一关，已通关可重玩；本店80关全部完成才解锁下一家。
当前落地暖心早餐店、街角简餐店各80关，共160关。餐厅、关卡、成绩和引导独立配置，可继续追加内容；若改变每店关数，需要同步课程分段与显示文案。

正常使用道具完成也推进关卡，但最佳无道具成绩单独记录。关卡GM演示不写通关，不假装推进餐厅；进度GM仅开放调试访问，通关计数仍以实际完成为准。
体力和广告格规则沿用当前版本：默认10、10分钟恢复1、通关免费、失败或退出一次扣1、同局去重；广告未接入则不发奖励。

多道菜订单卡优先显示当前未完成的一道，标题显示已完成道数，菜谱页可看全部需求，避免把色块文字缩得过小。

第1关介绍新餐厅与鸡蛋吐司，第6关加入牛奶咖啡，第16关加入鱼肉和米饭，第31关田园饭碗，第41关莓果奶昔；后续组合练习与挑战直至80关。设备沿用料理台、煎锅、饮料机，支持多配方。
第二家店继承已学道具，鸡蛋、牛奶、咖啡豆、鱼肉、米饭均为色块文本。新材料首次出现的关卡都配有教学标记。

## 引导模块
- TutorialFlow：纯状态机，支持dialog、click、swipe、demo；点击步骤必须命中指定目标，普通“下一步”不能绕过目标验证。
- TutorialView：顶部小型对话条、无暗罩高亮边框、棋盘真实滑动、目标点击转发与演示动画。
- 普通教学点击可用于认识UI；涉及实际操作时转发真实游戏动作，等待动作完成。菜谱教学真正打开菜谱页，等关闭后继续。
- 动画演示使用独立黄色小圆点演示节点，读取已验证路径，不修改正式位置、材料、背包、订单或步数。
- 完成教学按标识持久化；下次不重复。跳过本次不记录为已完成，重进该教学关会再次出现。
- 关卡GM提供重播引导；GM重播不写正常教学完成。离开页面清理遮罩、Tween、定时器与迟到回调。
- 无新内容的关卡不强行插入教学。增加新机制时必须补充引导定义、首现标记、目标映射和规则验证。

关卡元数据示例：introductions=['pan']表示本关首次教煎锅，availableProps=['undo']表示本关已开放撤回。教学定义guideFor返回步骤列表；配置目标如device:pan、orders、recipes、bag、action:right。
不要直接反复运行生成器覆盖手工编辑的关卡；需要重生成时先保留原版。现有六关原型Levels.ts和旧成绩kitchen-demo-v1保留，新链条用独立kitchen-campaign-v1，避免将不同布局的成绩冒充新关卡完成。

## 验收边界
160关均验证材料精确匹配、无需广告道具可解、最优路径可回放；最少步数2–22。canonical布局哈希对旋转和镜像归一后仍为160份。
真实玩家难度、节奏和教学文案仍需要试玩调优；算法最短步数不等于完整的人类难度评价。
正式美术、真实广告SDK、平台发布以及可视化关卡编辑器不在本轮交付中。本轮交付完整餐厅关卡链与引导，继续使用Cocos原生预览，无需打包。

当前引导UI已升级为不遮挡棋盘的顶部提示条；移动教学为棋盘真实滑动。动作播放期间隐藏提示，具体说明见docs/verification/2026-10-30-tutorial-swipe.md。


最新修订：所有发货教学已取消纯对话继续页，首关直接两次滑动；提示、高亮与厨师呼吸见docs/verification/2026-10-30-tutorial-action-chef.md。旧课程表中的‘对话’现为伴随操作的提示文本，不需要点击继续。
