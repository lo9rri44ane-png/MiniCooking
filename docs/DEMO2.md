# Demo2：装盘出餐试玩

基于 Cocos Creator 3.8.8。工程仍为当前目录，不需要构建安装包。

## 运行
1. 在当前 Creator 打开 `assets/scene/main.scene`，点击预览。
2. 首页底部点击 **Demo2 · 装盘试玩**，选择第1～5关；五关均可直接试玩。
3. 如预览仍是旧页面，刷新预览。建议竖屏720×1280或同比例窗口。

## 操作与规则
- 直接拖任意餐盒或金属盘：移动整盘及其中食物。长按盘内食物350ms再拖：单独取出。空地上的食物可以直接拖。
- 一次拖动可到任意可达落点，允许通路拐弯；松手吸附格子，不旋转、不拆分。提示位于棋子下方。
- 食物可装入任何几何容纳的餐盒。移动时不能穿越其他食物、餐盒或金属盘；仅原盘和目标容器允许进入/离开。原盘留下并继续占位。
- 上方订单直接显示目标颜色、形状和食物组合。不对应字母或食物ID。
- 餐盒须装满且匹配一个未完成订单，才可从同色、宽度足够的出口出餐。出餐后不可撤回。
- 空金属盘可从任意颜色、宽度足够的出口送洗；带食物的金属盘不能离场。
- 撤回只撤销当前出餐/送洗之后的移动；重试还原整关。
- 无步数限制、无计时、不消耗体力。完成全部订单即可结算，不要求洗完剩余盘子。

## 关卡与修改位置
`assets/scripts/features/demo2/Levels.ts`：五关尺寸依次6×7、7×8、8×9、8×10、8×12，订单4/6/8/10/12。食物与餐盒混排，后四关有额外重复彩盘供装盘/借位。第五关12份食物、29个盘体、占60/96格。三位客人同时展示全部订单，图标加大。出口大小严格按本关同色餐盒沿出口方向的最大横截面设置。

`tools/demo2-generate-levels.mjs`：用种子逆向构造、合法容器打乱，再用实际`actDrag`逐步验证。执行 `node --import ./tests/register.mjs tools/demo2-generate-levels.mjs` 会重新生成当前五关，属于关卡作者操作。路径只证明可行，不是最短解。

`Rules.ts` 为实际运行与测试共用规则；`Session.ts` 处理撤回边界；`Demo2BoardView.ts` 负责拖动、格子与轮廓；`Demo2Pages.ts` 负责页面和演出。当前 Solver 只回放验证可行路径，**不代表最短路径或自动生成难关**。新关卡的实际烧脑程度仍待真人试玩。

原生模板在 `assets/resources/prefabs/demo2`，含8个模块；动态容器/食品位置由关卡数据生成。要调整完整玩法应修改关卡数据与页面布局，并非只改静态预制体。

## 美术与存档
新图在 `assets/resources/art/latest/demo2`：六种完整食物、两种格子、清洗传送带。食物覆盖1～4格、含L形；色块与金属盘使用连续圆角轮廓渲染，可适配任意关卡形状。角色、背景、按钮、声音复用Demo1。

原件、裁切信息、哈希与总览位于 `art/demo2`。新图使用内置生图工具生成；没有接入付费生图API。AI生成素材不额外承诺独占版权。Demo1冻结目录未修改。

独立存档键 `mini-cooking-demo2-rect-v2` 仅记录五关通关；原Demo1进度和体力不在本玩法中写入。损坏存档明确报错并保留原件。
