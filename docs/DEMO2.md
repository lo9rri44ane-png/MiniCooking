# Demo2：装盘出餐试玩

基于 Cocos Creator 3.8.8、2D。首页点击“Demo2 · 装盘试玩”，常规练习为第1～11关，“极限借盒”为第12～19关；使用当前主场景预览即可。建议720×1280竖屏。建议重点体验新第18、19关，详见 [极限借盒说明](demo2/EXTREME.md)。

## 当前规则（2026-11-03）
- 仅保留食物和彩色餐盒。金属餐盘、送洗、空盘回收取消；食物直接落在棋盘上，空餐盒继续占格。
- 直接拖食物或餐盒；长按盒内食物350ms再拖可取出重装。餐盒整体移动时携带其中食物。
- 一次拖动允许沿可达通路拐弯，松手吸附；不可穿越其他食物、餐盒或锁区，不旋转、不拆分。
- 任一占格被锁区覆盖，整件元素均不能点击、拖动、手柄移动或长按取出；食品所属餐盒部分被锁时同样禁止取出。输入与运行规则共用此约束。
- 食物可装入任何几何容纳的餐盒；错误组合可取出纠正。装满并匹配当前已就绪客人订单，才能从同色且足够宽的出口出餐。
- 默认三个客人槽，每人最多两盒需求，每盒可含1～4份食品；入场及气泡弹出完成才接单。飞入订单→勾选→气泡收起→庆祝/烟雾离场→补位。演出不锁其他操作，候场订单不可提前交付；18/19关采用单客窗口。
- 出餐不可撤回；撤回仅影响上次出餐后的移动，不返时间。无步数限制、不消耗Demo1体力。
- 默认每关300秒；暂停冻结倒计时及演出；时间到停止操作并结算，重试重新计时。最后一单须在到时前完成，客人离场后显示胜利。
- 出口增加约0.85格边缘响应与横向吸附容差，仍经过真实路径、颜色、宽度和订单校验。

## 关卡
原五关按无金属盘规则重构，尺寸仍为6×7、7×8、8×9、8×10、8×12。第6～11关新增至少6格的连续矩形备餐封锁区，包含完成本关必须使用的食物。

|关卡|解锁变种|
|---|---|
|6|出餐1单，开放9格备餐区|
|7|出餐2单，开放8格储备区|
|8|红色订单1单，开放6格|
|9|蓝色订单1单，开放12格|
|10|双区域：累计1单/3单，分别开放8格/6格|
|11|双区域：黄色订单1单/累计4单，分别开放6格/6格|

关卡以 `assets/scripts/features/demo2/Levels.ts` 为准；`tools/demo2-generate-levels.mjs` 使用种子逆向构造、可逆打乱，使用运行时actDrag回放所有存储解。这里只证明可行，不代表最少操作数或真人难度已验收。出餐顺序兼容三位客人的轮换队列。

### 组合装盒与腾挪（本轮更新）
第6～11关依次有1/1/2/3/3/3个双食物订单，食品数为7/9/10/13/13/15。包括4格餐盒放L形3格+1格、两份横向2格，以及2格餐盒放两份1格。按食物类型、形状和相对位置匹配，不绑定食物或餐盒ID。新极限组进一步使用四个1格、2+1+1等完整组合，客人额度按最多两盒计算。

后段加入需腾位的额外餐盒及搬移链。第9～11关初始并集占用率为72.5%/71.25%/72.92%。占用率只算真实覆盖，不重复计盒内食物。审计直接组装出餐（不搬障碍）后，第9/10/11关仍有2/0/1条初始直通方案；因此仅第10关已排除这种开局捷径，不能将所有后段宣称为必须先腾挪或最终难度已验收。详情见 `docs/demo2/DIFFICULTY.md`、`density-audit.json`、`shortcut-audit.json`。生成器默认防止覆盖当前密集组合数据，作者流程见难度文档。

订单现在使用Demo2独立单双款气泡，保留柔和奶油金边风格。两格鱼、面包、莓果、玉子烧及L形华夫饼逐张重画；L图右上缺格的alpha像素为0，完整主体仅等比缩放/平移，没有mask截掉主体。棋盘食物按占格比例留白，不再给宽高各减固定像素。
