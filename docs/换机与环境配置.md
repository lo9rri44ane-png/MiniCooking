# 换机与技能用法

## 环境

1. 安装Node.js22+、Cocos Creator3.8.8；AI工作流/资源处理另需Python3.10+。
2. 在仓库根目录执行 npm run setup，安装锁定依赖并编译MCP扩展。
3. Dashboard打开本目录，等待导入，打开assets/scene/main.scene预览。不要重建UUID。
4. 在Creator启用工程内cocos-mcp-server，HTTP端口31388；Codex重新加载连接后先核对project路径。

实际编辑器路径可写入不提交的config.local.json，或设置COCOS_CREATOR_PATH。本项目不依赖旧电脑磁盘目录；MCP只控制本机，无需API Key。

## 默认工作方式

先读README、AGENTS；按任务读取[架构](ARCHITECTURE.md)、[待办](BACKLOG.md)、[美术规范](standards/ART.md)。不要逐个加载全部skill或历史会话记录。

项目精简后的11个skill与用法在[SKILLS](SKILLS.md)，匹配任务即使用，无需每次写名称。全局内置imagegen/电脑工具不属于本工程清理范围。

## 微信与迁移

当前Demo1=1.0.1，AppID与发布证明见[DEMO1](DEMO1.md)。微信开发者工具需登录并由用户开启服务端口；上传开发版与后台设为体验版是两个动作。没有自动发布任务。

本地存档不随Git迁移，也未提供云同步。历史归档和发布ZIP默认不进入Git；换机需要时另行复制archives及releases目录。常规继续开发所需当前源码、资源、元数据、测试和11个skill仍在工程。
