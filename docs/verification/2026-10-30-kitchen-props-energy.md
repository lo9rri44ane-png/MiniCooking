# 道具、体力和 GM 试玩说明
日期：2026-10-30。Creator3.8.8，直接预览，无打包。

## 使用入口
- 顶部体力按钮：显示当前点数及恢复倒计时，点击打开体力 GM（+1、+5、补满，上限10）。首页、选关和关卡均有入口。
- 关卡标题右侧“关卡GM”：增加3步或10步；最优路径会清空当前操作、背包、暂存和制作进度，重置关卡后按真实移动规则自动演示通关。不是直接把订单改为完成。
- 游戏下方三种道具按钮；失败结算中也提供续玩入口。

## 当前试玩细则
| 功能 | 行为 |
| --- | --- |
| 加班 | 增加3步，每局一次；步数失败后可原局续玩 |
| 撤回 | 恢复上次完整有效滑行前的位置、材料、背包、订单与补位状态；暂存同步恢复，不复制材料；没有历史或已通关时不可用 |
| 暂存1格 | 选一份背包材料放入独立暂存区，点击按钮手动取回，不耗步；暂存材料不参与制作，需先取回；取回达到背包容量照常立即失败 |
| 失败挽救 | 满包后可以暂存腾一格或撤回；原失败已扣的体力不退还，同局再失败／退出不重复扣 |

道具当前标注“试用”，不消耗库存，撤回暂不限制次数以便测试；尚无真实广告播放和支付。不能将本地试用计为已看广告或已付款。
使用道具或关卡GM的成绩不覆盖正常无道具最佳记录。正常制作和路线未改变，六关原最短解继续有效。

## 体力规则
- 初始与自然上限10点，未满时每600秒恢复1点，保留不足10分钟的时间进度；满体力不积攒额外恢复时间。
- 开局不预扣，但必须至少有1点；正常通关不扣。
- 本局首次失败扣1点；未失败而中途重试、选关、退出或刷新也扣1点。失败后再退出或重试旧局不重复扣，新开局重新计算。
- 本机保存点数、恢复起点和进行中局次；后台时间计入恢复。浏览器关闭刷新尽量在pagehide结清；异常中断未结局下次加载处理一次。
- GM重置演示和关卡GM加步进入调试模式，不额外扣体力、不写正常最佳；之前已经产生的失败消耗不会退款。
- 存档无效时保留原件并阻止正常开局，不静默重置覆盖。本地时钟与本机存档为Demo实现，未来正式在线经济应再接服务端校验。
