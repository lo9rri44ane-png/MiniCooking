## 修复
- 新PNG最初仅导入Texture，导致SpriteFrame路径不存在：通过原生save-meta/reimport修复，保留UUID。
- 拖到棋盘外被触发TOUCH_CANCEL：扩大透明交互范围，并显式更新预制体保留布局后的命中区。五关真实拖出验证通过。
- 预制体原有Graphics遮挡格子Sprite：与既有框架一致，采用独立ArtVisual子节点，修正背景层级。
- 暂停同步暂停送餐Tween；退出释放计时、Tween、动画、音频和资源。
