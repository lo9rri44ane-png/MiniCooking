# 资源交付说明

resource-list.csv 是待制作与复用清单，当前正式插画、动画、音频均未交付；色块和文本预制体已在工程。现有160关共享食材、设备与UI，不需要160套素材。

建议目录：assets/art/{characters,customers,food,devices,board,ui,backgrounds,fx}，音频 assets/audio/{sfx,bgm}。本轮不创建空美术目录来冒充资源。命名采用表中id，PNG透明背景，动态图标的文字/数量继续用Label。图片导入为SpriteFrame；UI底板使用Creator原生九宫格。食材图集、UI图集、角色与背景分开，实际DrawCall和压缩效果需真机验证后再定。

先做P0：厨师、12种食材、3设备、棋盘、通用底板；其次P1：10种菜品成品、首页/厨房背景、客人、图标；最后P2：粒子与音频。尺寸为建议源图规格，并非已经测定的内存预算。交付需包含源文件、导出图、授权来源和预览图。

预制体替换：在绑定节点上添加Sprite并指定SpriteFrame，保留PrefabSlot.bindingKey和UITransform；不删除命中区或Button。PrefabSlot的preserveStyle可让字体/颜色由预制体控制，preserveLayout可让静态布局由编辑器控制；默认关闭，避免影响数据驱动格子尺寸与状态颜色。厨师、食材、背包、设备的位置/数量仍由玩法决定，不应开启preserveLayout。正式美术不应直接覆盖CSV的“已实现”状态，验收后再更新。
