## Intent
用户明确认为上一轮仍过简单。难度应来自食品可收纳进餐盒而减少棋盘占位，需要先借盒收食物、移动其他盒子、再取出重组。不能只堆空挡块或拉长随机逆序证明。

## Scope
保留Demo1、Demo2现有11关，新增独立极限组（六个紧凑关12～17，再加大规模18/19，共8关）。默认仍300秒，UI常规/极限分组容纳更多关卡。无新物理规则、不旋转、不拆食物、不恢复金属盘/回收、不发布或推送。

## Tasks
- [x] 全组合目录：精确覆盖当前八类食品在1～4格连通餐盒形状中的合法平铺；同种食品不同实例不重复计数，不把摆放方向或位置不同的方案漏掉。输出可审计目录和覆盖报告。
- [x] 极限作者/求解器：shipping actDrag为唯一合法性依据；高食物密度，真实借盒/压缩占位，错盒临时收纳后取出重组，装满移动过狭道、单/双空位搬移、互锁出餐/解锁区等组合设计，至少6个实际可玩的极限关卡。
- [x] 必要性验证：每关给合法路径，至少对首个送餐前提供“禁用借盒收纳则不可解”或受控穷举的反事实证据；有预算上限必须报告未知，不能当不可解。存储证明长度不是最优难度。
- [x] 全组合口径按推荐方式接入并已明示：每客至多两盒需求，每盒按餐盒面积可含1～4份食品。原最多两食品上限不再截断食谱，气泡仍只有两张餐盒图标。
- [x] 选关/存档扩展及引导文案：保留旧通关、本地损坏保留；新增极限标记/数量浏览，不读写玩家真实存档做测试。
- [x] 单测/类型检查/实际拖拽回放与截图，特别是临时食品收纳、不同形状盒组合、取出重组和客人就绪。

## Acceptance
Given 全组合目录, when 对每项计算占格并集, then 无重叠且恰好填满对应色块，不绑定食品ID。Given 极限关卡, when 依shipping规则回放, then 可胜且存在食品入临时盒、带载搬移、取出重组的实际动作；有严格证据才宣称这些动作对胜利必要。Given 超出预算的搜索, then 清楚标记未知，不冒称极限/最优已证明。
