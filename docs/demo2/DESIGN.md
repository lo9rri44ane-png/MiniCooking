# Demo2 设计冻结 v0.1
用户已确认：6×6无透视矩形网格；完整食物占1~4格，不旋转；4色底盘无ID/预印轮廓，食物不绑定盘子身份；食物可取出，原金属盘留在原位；空盘可从任意尺寸足够的四向出口送洗；订单在上方最多4位客人同时展示，多单用装好食物的彩色块表示；装满且满足当前任意订单才按色块颜色出场，不可撤回出场。至少5关递增，4/5关5/6单。无步数限制，无体力/广告失败。

实现裁决：拖食物移动/装入/取出，拖底盘边框或手柄整体移动；原盘带食物也可整体搬动。松手落格；一次动作横或竖；承载容器移动时附属食物跟随。可撤回未发生出场的动作，出餐/回收作为不可逆边界清空撤回记录。全部订单同时生效，无FIFO，4客人可各接多单。胜利为全部订单完成，不强制清空已不挡路的空盘。

边界：本轮独立试玩入口；Demo1保持，原素材只读；不发布/推送/打包。新资源放art/latest/demo2，源文件和审计放art/demo2，原生模板prefabs/demo2。

允许的内容：无挂载ID的订单按颜色/底盘形状/食物类型及相对格子组成匹配。局部装盘仅检查实际空间，不通过隐藏绑定禁止食物；错误组合不能出场，食物可取出纠正。5关用真实规则回放验证；若完整全状态最短搜索预算不够，必须明确仅有可行路径/上下界，不伪称最优。
