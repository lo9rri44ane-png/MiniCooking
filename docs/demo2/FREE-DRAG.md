# Demo2 自由拖动交互 · 2026-11-02

用户确认：装好的彩色餐盒任意位置直接拖动整盘；长按食物350ms后可单独取出。金属原盘中的食物直接拖动。放大/保留把手兼容原操作。

一次拖动支持横纵同时变化，以松手的吸附格为目标；算法检查对象完整形状是否存在不穿越障碍的正交通路，可途中拐弯。不旋转、不拆分、不消耗途中盘中食物。食物沿用既有拿起规则，可从容器上方经过，但不能穿过其他食物；落点必须完全进入一个容器或空地。整盘始终受全部容器和其他食物阻挡。未匹配订单不能出场；出场只可能是路径最后一步。

交互：抬起对象、自由跟手、形状落点轮廓与通路预览；非法落点回原位，取消/暂停/多指不得误提交。长按切换在移动超过10逻辑像素前触发，松手/销毁立即清理计时。

一次自由移动为原子操作，只产生一条撤回记录；出餐/送洗仍不可撤回。保留底层直线act供旧证明路径调用，新增actDrag/planDrag在交互和Session共用。
